# Critical Failure & Severity Taxonomy (การจำแนกระดับความรุนแรงและข้อผิดพลาดวิกฤต)

## 1. ลำดับชั้นความรุนแรง (Severity Hierarchy)

| ระดับ (Severity) | ผลกระทบต่อผลงาน | สิทธิ์ Veto | การกระทำที่ระบบต้องทำ |
| :--- | :--- | :--- | :--- |
| **INFO** | ข้อสังเกตเล็กน้อย ข้อเสนอแนะเชิงสำนวน หรือคำแนะนำเสริม | ไม่มี | แสดงเป็นคำแนะนำทางเลือก ไม่หักคะแนน |
| **LOW** | ข้อสะดุดเล็กน้อย จังหวะคำหรือคัทที่ไม่ลื่นไหล | ไม่มี | หักคะแนน 1-3 คะแนนในหัวข้อย่อย |
| **MEDIUM** | ปัญหาความต่อเนื่องหรือความน่าเชื่อถือที่ทำให้คนดูฉุกคิด | ไม่มี | หักคะแนน 4-7 คะแนน บังคับแสดงใน Issue List |
| **HIGH** | ช่องโหว่สำคัญของพล็อต, ข้อมูลจริงคลาดเคลื่อน, ตัวละครทำลายความน่าเชื่อถือ | ไม่มี | หักคะแนน 8-15 คะแนน ผลงานอาจติดสถานะ `PASS_WITH_NOTES` หรือ `REVISE` |
| **CRITICAL** | ข้อผิดพลาดร้ายแรงที่ทำลายรากฐานของผลงาน หรือข้อเท็จจริงผิดที่ยืนยันด้วยหลักฐาน | **มีสิทธิ์ Veto** | **บังคับตีกลับเป็น `REVISE` หรือ `REJECT` ทันที แม้คะแนนรวมจะได้ 80-90+ คะแนน** |

## 2. ตัวอย่างข้อผิดพลาดระดับ CRITICAL (Confirmed Critical Failures)
1. **ตัวละครเสียชีวิตแล้วกลับมาโดยไม่มีคำอธิบาย:** ยืนยันการตายชัดเจนแล้วเดินกลับเข้ามาในฉากถัดไปเหมือนไม่มีอะไรเกิดขึ้น
2. **ขัดแย้งกับข้อเท็จจริงโลกจริงที่พิสูจน์ได้เด็ดขาด:** ในงานประเภทความรู้/สารคดี เช่น การระบุปี พ.ศ. สำคัญผิดจนประวัติศาสตร์เพี้ยน หรือให้สูตรผสมสารเคมีที่เป็นอันตรายถึงชีวิต
3. **ขัดแย้งกับกฎโลกสมมติที่ตนเองตั้งไว้อย่างโจ่งแจ้ง:** ในโลกที่ปูว่าไม่มีใครใช้เวทมนตร์ได้นอกปราสาท แต่ตัวละครเดินไปเสกไฟกลางทุ่งโดยไม่เฉลย
4. **ความขัดแย้งของมุมมองผู้เล่าในเพลง (Song POV Collapse):** ในเพลงเล่าเรื่องจากมุมมองของคนที่ตายไปแล้ว แต่ท่อนท้ายกลับบอกว่ากำลังนั่งมองลูกเติบโตในปัจจุบันโดยไม่มีบริบทวิญญาณ
5. **Character Identity แตกสลาย:** หน้าตา เสื้อผ้า เพศ หรือลักษณะทางกายภาพเปลี่ยนไปคนละคนในช็อตต่อเนื่องโดยไม่มีเหตุผลทางเนื้อเรื่อง

## 3. สิ่งที่ห้ามตัดสินเป็น CRITICAL (Forbidden False Positives)
ห้ามใช้ CRITICAL กับกรณีต่อไปนี้เด็ดขาด:
- **ความชอบส่วนตัวหรือรสนิยมของ AI (Subjective Taste):** เช่น ชอบทำนองช้ามากกว่าทำนองเร็ว, ชอบตอนจบแฮปปี้มากกว่าตอนจบเศร้า
- **การใช้ภาษาเปรียบเทียบหรืออุปลักษณ์ (Metaphors & Poetic License):** เช่น *"หัวใจฉันแตกสลายกลายเป็นธุลี"* (ห้ามมองว่าผิดฟิสิกส์ว่าหัวใจมนุษย์กลายเป็นผงไม่ได้)
- **การทดลองทางศิลปะ (Artistic Experimentation):** เช่น การตัดต่อแบบ Jump Cut โดยตั้งใจเพื่อสร้างความกระวนกระวายใจ
- **กฎแฟนตาซีที่โลกสมมติรองรับ:** หากเรื่องกำหนดว่ามนุษย์สามารถหายใจในน้ำได้ด้วยผลึกแก้ววิเศษ ห้ามฟิสิกส์จัดเป็นข้อผิดพลาด
- **ข้อเท็จจริงที่ยังไม่ชัดเจนหรือขาดหลักฐานยืนยัน:** ให้จัดเป็น `UNVERIFIED` ไม่ใช่ `CRITICAL`
